NexIT Solutions' working repo for **Finance Land** (website build, then marketing). It holds the brief, the
hard rules, the current status and a log of every work session, so any person or AI assistant can pick the
project up.

| [`rules/client.json`](rules/client.json) | Names, channels, locations of files and tools | Project owner only |

# Session logs

One file per work session, named `YYYY-MM-DD-name.md` (add `-2`, `-3` for more sessions on the same day).
Add files only. Never edit or delete an earlier log.

```
# YYYY-MM-DD · Name · Tool used (Claude.ai, Claude Code, ChatGPT ...)

## Asked
What the session set out to do.

## Done
What was actually completed, with links or file names.

## Changed
Anything that changed on the site, in the approval sheet, or in this repo.

## Open
What is unfinished, waiting on someone, or needs the owner.
```
